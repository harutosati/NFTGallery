# NFTGallery

A Secure NFTGallery Explorer for Multi Chain Support and Real Time Data Analytics.

NFTGallery is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- A Secure NFTGallery Explorer for
- Multi Chain Support and Real
- Time Data Analytics

## Key Features

- A Secure NFTGallery Explorer for
- Multi Chain Support and Real
- Time Data Analytics

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/NFTGallery.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure NFTGallery, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
